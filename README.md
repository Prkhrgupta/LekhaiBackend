# Lekhai

Accounting for Indian MSMEs — secure, cloud-based, and customisable per business.

## Features

- **Secure and correct accounting, every time** — double-entry ledger posting with row-level security per shop, so books stay accurate and tenant-isolated
- **Fully cloud-based** — one account across web, desktop, and mobile
- **Highly customisable** — role- and feature-based configuration tailored per customer and category
- **GST support & E-Way Bill automation** — GSTIN verification and EWB generation via GSP (TaxPro)
- **Keyboard-friendly** — familiar navigation for long-time Tally users
- Ledgers, vouchers (payment/receipt/contra/journal), inventory masters, account masters, and Excel import/export
